# TRX Physio Therapy & Chiropractic Center

This is a website for TRX Physio Therapy & Chiropractic Center. The website is built with Django.

## Installation

1. Clone the repository
2. Install dependencies with `pip install -r requirements.txt`
3. Run `python manage.py migrate` to apply database migrations
4. Run `python manage.py runserver` to start the development server
